# Quad

Go rectangle-pattern exercises from the 01Edu piscine.

`Quad.go` defines `QuadA` through `QuadE`, which print borders and corners using nested loops and `github.com/01-edu/z01`.

## Usage
These are educational functions, not a standalone executable. Call a chosen function from an appropriate exercise harness with width and height arguments. Dependencies are declared in `go.mod`.
